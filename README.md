# BugBoard

## Descrizione
**BugBoard** è una dashboard intuitiva e performante progettata per team di sviluppo che hanno bisogno di tracciare issue, bug e task in modo rapido. 

## Caratteristiche Principali
* **Gestione Task:** Crea, modifica e chiudi issue con un click.
* **Filtri Intelligenti:** Filtra per tag, priorità e tipologia di task.
* **Design Responsive:** Ottimizzato per desktop e mobile.


## Tecnologie Utilizzate
* **Frontend:** Angular, Tailwind CSS
* **Backend:** Node.js, Express, Sequelize
* **Database:** PostgreSQL

## Come iniziare
Segui questi passaggi per far girare il progetto in locale:

### Prerequisiti
Assicurati di avere installato:
* [Node.js](https://nodejs.org/) (versione 18+)
* [Angular CLI](https://angular.io/cli)

### Installazione e Avvio
1. Clona il repository:
   ```bash
   git clone [https://github.com/mic0099/BugBoard.git](https://github.com/mic0099/BugBoard.git)

2. Vai nella cartella:
   ```bash
   cd bugboard/backend

3. Installa le dipendenze:
   ```bash
    npm install

4. Avvia il backend:
   ```bash
   docker-compose up -d

5. Vai nella cartella del frontend:
   ```bash
   cd bugboard/frontend

6. Installa le dipendenze:
   ```bash
   npm install

7. Avvia il forntend:
  ```bash
  ng serve 

8. Lapplicazione è ora disponibile all'indirizzo: 
    ```bash
    http://localhost:4200
